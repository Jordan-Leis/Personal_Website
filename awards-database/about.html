What this is

Waterloo Awards Finder is an independent, unofficial project that mirrors the University of Waterloo's public Awards Directory into a fast, instantly-searchable page. The official directory is a real-time, one-award-at-a-time search tool built on the university's student records system; this site periodically copies its publicly-visible listings so students can search and filter all of them at once, client-side, with no page reloads.

What this is not

This site is not affiliated with, endorsed by, or operated by the University of Waterloo. It is not an application system — you cannot apply for awards here. For anything time-sensitive (deadlines, eligibility rules, required documents, how to actually apply), always confirm against the official Awards Directory, which is the authoritative source. Data here can be out of date between refreshes.

How the data is kept up to date

A scheduled, automated job re-scrapes the official directory three times a year (around January, May, and September) and republishes the results here. The refresh date and award count for the current dataset are shown in the footer of the search page. If a scheduled refresh produces a clearly broken or suspiciously incomplete dataset, it's designed to fail and leave the previous, known-good data in place rather than publish something wrong.

Known data gaps

Two filters shown on the official site's search form are not available here, on purpose, rather than being faked:

  • Citizenship status (Canadian/Permanent Resident vs. International) — this isn't captured per award. Testing showed that filtering by a single citizenship value on the official site silently excludes a large share of awards that have no citizenship restriction at all, so this data can't be reliably reconstructed per award.
  • Selection process (application required vs. automatically considered) — this is used internally by the official search tool but isn't exposed as a stored field per award, so it isn't available to mirror here either.

Check the official directory directly if either of these matters for your search.

Data access

The mirrored data is published as plain JSON if you want to build something with it:

  • data/index.json — manifest: freshness, counts, and every filter value in use (~6 KB)
  • data/awards.slim.json — all awards without the long description text (~455 KB)
  • data/awards.json — everything, all fields (~2.6 MB)

This is an unofficial mirror, not a University of Waterloo API. There is no stability or availability guarantee, the data is only as fresh as the last refresh shown in the footer, and anything time-sensitive should be verified against the official directory. It updates about three times a year, so please cache it rather than polling.

Your data / privacy

The "Match my profile" feature stores your selected program/level/area of study only in your own browser's local storage. Nothing you enter here is sent anywhere or seen by anyone else.

Questions or issues

This is a small independent student project. If something looks wrong or broken, the source code for both the scraper and this site is public — see the project's GitHub repository.
