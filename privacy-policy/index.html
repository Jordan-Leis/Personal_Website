Jordan Planner Privacy Policy

Last updated: 2026-10-11

Jordan Planner (“the app”) is a personal productivity tool that powers jordanleis.com/to-do and jordanleis.com/schedule. It is built and used by a single person, Jordan Leis, and is not offered to the public. Sign-in is restricted to the owner's account.

What the app accesses

  • Google Calendar: reads events to find free time, and creates or updates time-block events and events detected from email invitations, in the owner's own calendars.
  • Gmail (read-only): reads new messages to detect calendar invitations and interview or meeting confirmations. Message content is processed in memory and is not stored. Only the message ID, the result, and (for items needing review) the subject, sender and candidate times are kept.
  • Account info from Google sign-in (name and email), used only to restrict access to the owner.
  • Tasks and proof files that the owner enters or uploads.

What the app does not do

  • It does not sell, share, or transfer any data to third parties.
  • It does not use data for advertising, and it does not send email content to AI or LLM services.
  • It does not send email or modify or delete Gmail messages.

Where data is stored

Task data, calendar mirrors and proof files are stored in a private Supabase (Postgres and Storage) project, protected by row-level security so that only the owner's signed-in account can read them. Scheduled sync jobs run on GitHub Actions using encrypted secrets.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept for as long as the owner uses the app. Access can be revoked at any time from Google Account permissions, and all stored data can be deleted by deleting the Supabase project.
